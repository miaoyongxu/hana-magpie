# Changelog

## 1.0.0

- First public release.
- Magpie/OpenCode provider-plugin host, API key and OAuth sign-in, multiple
  accounts, model discovery and `auth.usage` quota windows.
- Magpie-style Providers UI with subscription, plugin, API-key and relay
  categories; search, enable/disable, account management, per-model save,
  test and quotas.
- Loopback gateway for Chat Completions, Anthropic Messages, Responses and
  Gemini, with routing groups and account failover.
- HanaAgent provider sync, agent model picker integration, usage accounting
  and a read-only agent status tool.
- Follows the HanaAgent theme and sets a Magpie face on its card-center page
  card on first use.
